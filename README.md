# 🧬 About Me

I'm **Divyansh Singh Patel**, publicly known as **ItzByteGlitch**.

I'm a developer who enjoys jumping between **AI, web applications, cloud infrastructure, Minecraft, games and experimental projects**.

I like taking an idea from:

```text
Idea
  ↓
Prototype
  ↓
Break it
  ↓
Fix it
  ↓
Ship it
  ↓
Make it better
```

I'm especially interested in building software that combines multiple areas of technology rather than staying inside a single stack.
